## 1. 準備チェックリスト
- [ ] 耐熱容器（マグカップまたは深めの小鉢）
- [ ] 重曹（大さじ1）
- [ ] 水（200ml）
- [ ] ふきん（またはキッチンペーパー）

## 2. 清掃フロー

```mermaid
graph TD
    A[耐熱容器に水200mlと重曹大さじ1を混ぜる] --> B[500W〜600Wで約3分加熱]
    B --> C[扉を開けずに15分放置しスチームを充満]
    C --> D[浮き上がった汚れを拭き取る]
```

## 3. トラブルシューティング
- **汚れが落ちにくい場合**: 加熱時間を1分延ばすか、放置時間を長めにとって蒸気を十分に行き渡らせてください。
- **焦げ付きがある場合**: クエン酸（大さじ1）を使った同様のスチーム清掃をお試しください。

:::caution[火傷に注意]
加熱直後の容器は非常に高温です。必ず冷めるまで待ってから取り出してください。
:::
